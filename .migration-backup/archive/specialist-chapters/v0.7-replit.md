## One-sentence claim

An agentic build environment is a different instrument from a chatbot, so its
fair test must include repository boundaries, executable behavior, and public
verification rather than answer quality alone.

## Lesson

Tool category is part of the prompt. Before asking a build environment to
change an artifact, inspect the repository, agree on boundaries, make the
smallest useful change, and test the real result.
