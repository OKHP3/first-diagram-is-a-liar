## One-sentence claim

Turning written process steps into a readable flowchart is not the same as
modelling process semantics, so a bounded text-first BPMN path can preserve
roles, events, gateways, and handoffs without pretending to be a full engine.

The draft uses the public project's explicit boundary: `bpmn-beta` is a

## Lesson

The useful compression is not a prettier pile of boxes. It is a traceable path
from written process narrative to structured model to diagram to review and
handoff.

## Article update

Add a process-semantics bridge after the discussion of diagram structure in the
future editorial cut:

> A flowchart can describe a process without carrying the process's meaning.
> BPMN for Mermaid tests a smaller bridge from written narrative to structured
> process model to visualization, while keeping the prototype boundary honest.

Keep the non-goal visible: this is not a complete BPMN engine or an upstream
Mermaid feature. Do not change the current external v0.5 page as part of this
