# Evidence archive

The application at the repository root is the working tutorial. This folder
holds the source material that makes the tutorial inspectable.

- `diagramming-shootout/` is the preserved ETCH-AI-SKETCH experiment: brief,
  prompts, Mermaid sources, rendered images, public links, and decks.
- `specialist-chapters/` is the compact blitz-release packet for the v0.6
  Notion, v0.7 Replit, v0.8 Mermaid Theme Builder, and v0.9 BPMN for Mermaid
  companion chapters.
- `member-deliberations/` holds the Replit specialty-role records.
- `editorial-cut/` is the prepared local HTML article cut. It is not evidence
  of a deployed v1.0 publication.
- `legacy-exports/` holds selected source captures and older exports that were
  worth preserving after the Replit attachment buffer was triaged.

The archive is evidence, not a second runtime. The root application is the
canonical interactive surface for this repository.
