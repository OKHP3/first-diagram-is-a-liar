# Historical Source Captures

These are preserved imports, not current application source.

- `prompt-captures/` contains the lightly unprocessed drafts and prompts behind
  the article and council record.
- `presentation-imports/` contains imported deck and PDF artifacts. The
  publication-ready deck family is indexed under the ETCH archive's `slides/`.
- `web-snapshots/` contains imported web assets retained for provenance.

Names were normalized for portable paths during the application migration. The
original locations and intent are recorded in the Git history and
[`MIGRATION.md`](../../MIGRATION.md).
