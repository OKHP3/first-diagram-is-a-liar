## Post copy

Notion was not another model in my Mermaid experiment.

It was the writer's room behind it.

I used Notion to keep the PRD, drafts, revisions, model interviews, and links to the Mermaid source together. That gave me somewhere to return when the chat windows were closed, see how the story changed, and find the artifact behind a claim.

That mattered because a multi-model experiment is not just a pile of answers. You need to know what each answer came from and what changed between versions.

The roles stayed distinct:

AI conversations generated possibilities.

Notion held the navigable editorial record.

GitHub preserved the source and rendered receipts.

Notion did not judge the diagrams or join the Core Five. It served as archivist and synthesizer, with a different brief and a different job. Its V1 diagram is a useful receipt for the Prose → Visual → Ship loop, not a scorecard entry.

The lesson: memory helps make work reusable, but storage alone does not create understanding. You still need to check the source, preserve the revision path, and decide what the evidence supports.

Where does your work live after you close the chat window?
