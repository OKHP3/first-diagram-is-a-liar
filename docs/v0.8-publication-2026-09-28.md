## Published LinkedIn article addition

### v0.8: Bottling the Visual Lightning

I gave ChatGPT, Claude, Gemini, Perplexity, and Copilot the same diagramming instructions and got different diagrams. That was expected: each model made different choices about what to include, how to organize it, and what deserved emphasis. The surprise came when I supplied the same Mermaid code. The results looked much closer, yet the colors, fonts, and line treatment still varied in the previews I used. They did not look like one corporate diagram set.

That changed the problem I wanted to solve. I wanted a postprocessor that could take an existing diagram and apply a reusable visual style. And when I stumbled onto a theme that worked, I wanted to bottle that lightning so the next diagram could use it too. A good palette should not require another round of negotiation every time somebody needs three boxes and an arrow.

Then I started thinking about HTML and CSS. What if the diagram prompt came with a style file, so the AI received both the content brief and the visual expectations? Mermaid already has theme configuration for colors and fonts, so the useful idea was a reusable styling contract that could be applied to the code. An adjacent CSS file was an analogy, not a promise that every Mermaid host would load it.

That line of thinking became Mermaid Theme Builder, a workbench for applying palettes and typography to Mermaid code, previewing the result, and exporting styled code or prompt scaffolds with a target renderer in mind. It works on the visual layer around a diagram you already have. It does not decide what the diagram means, and it cannot make every host behave identically. The destination still needs checking.

The hindsight arrived with Agent Skills. Had I understood them a month earlier, I might have started by packaging the instructions, theme assets, and styling checks as a skill. That could have coached generation and carried an application workflow together. It would still need tools that apply the configuration and a check of the actual rendered result. Instructions are useful; visible evidence is what tells me they worked.

Mermaid Theme Builder and its current scope: https://overkillhill.com/projects/mermaid-theme-builder/

Diagrams that belong together should look like they belong together.
